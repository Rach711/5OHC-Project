# 5-OH-C_Project
This project was to investigate how sequence context affects the repair of 5-OH-C. model of NTHL1 and DNA was simulated with 6 different hotspot and non-hotspot pairs to look into DNA shape and structure differences.

Scripts 1 to 7 establish these 6 hotspot pairs.

Scripts 8 to 9 prep the files and carry out the simulations.

Scripts 10 to 11 visualise the data.

Scripts 12 to 14 process the data for machine learning.

Scripts 15 carry out the machine learning models, with 15b conducting a sanity check on the K-Means model.
Scripts 16 perform feature selection.

Scripts 17 to 18 prep the files and process the output of RING.
